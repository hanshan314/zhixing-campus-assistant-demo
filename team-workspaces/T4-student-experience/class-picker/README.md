# 轮到你啦 · DeepSeek Harness 账号与抽签插件 v2.2

本机账号登录，每个账号可创建多个抽签场景。指定数量随机抽选，确认参与后计数，参与较少的对象在后续抽选中获得更高权重。中文界面、离线使用、无第三方前端依赖。

## 四种场景

| 场景 | 抽选对象 | 用法 |
| --- | --- | --- |
| 老师抽班级 | 整个班级 | 从任教班级中抽取活动、展示或检查班级 |
| 班级内抽签 | 同学 | 班级活动、课堂抽签、值日安排 |
| 社团抽签 | 社团成员 | 成员活动、值班、任务安排 |
| 学生会选人 | 候选人员 | 活动组织或各部门任务人员安排 |

账号身份决定注册后的默认场景，所有账号均可另建其他类型的场景。身份用于组织工作台，不代表学校认证，没有额外查看其他账号数据的权限。

每个场景独立保存名单、导入前次数、活动记录、待确认结果与抽选设置。同名人员在不同场景中分别计数，老师场景则按班级计数。

## 账号

注册时填写用户名、显示名称、身份和密码。用户名为 3–32 位文字、数字、下划线、点或短横线，字母不区分大小写；密码为 8–128 个字符。

右上角“账号设置”可退出登录、修改显示名称和密码。修改资料需要当前密码，保存后其他旧登录失效。登录最多保持 7 天，连续输错密码会暂时限制尝试。

后端检查场景归属，各账号只能读取、修改自己的场景。本版本没有跨设备同步或邮件找回密码服务，请记住密码并定期导出场景备份。

密码使用随机盐与 scrypt 派生值保存；凭证使用 HttpOnly、SameSite Cookie，磁盘只保存凭证摘要。场景备份不含账号密码，名单本身没有额外加密。

## 旧版升级

旧版名单、活动与待确认结果不会被清空。注册页发现旧数据时，提供 **“把旧版名单与活动记录归入此账号”** 选项。选中后将其作为“班级内抽签”场景归入新账号；旧数据只能领取一次。尚未领取的数据不会出现在已注册账号的工作台中。

首次保存 v2 时，原始 v1 文件另存为 `state.json.v1-backup`，不被日常备份覆盖。迁移后的主文件是账号结构，旧版插件不能直接读取；回退前须停止服务，使用保留的 v1 文件。旧版导出的 JSON 仍可在班级内抽签场景恢复。

## 使用

1. 注册或登录，在左侧选择场景；点击旁边的“＋”创建场景，选择类型并填写名称。
2. 点击导入，直接粘贴原始名单或导入 UTF-8 的 TXT / CSV / TSV。支持 Excel 复制、空格、制表符、逗号、Markdown 表格和“姓名：…”的文字，无需统一列顺序。老师场景识别班级，其他场景识别人员。
3. 名单自动识别后先显示可编辑预览，核对姓名、学号或编号、部门、职位、班级或分组与历史次数。缺少的信息留空，缺少次数按 0；可修改识别结果、勾选或跳过记录，再确认导入。此时才会保存名单。
4. 设置活动名、数量与基础权重，可在下方五张卡片中组合设置规则，再开始抽选。同次不重复，点击“确认参与并记录”后才增加次数。重新抽选或取消不计数。
5. 活动记录可撤销，次数和权重同步回退，撤销记录保留可查。

名单支持按姓名、学号、部门、职位等搜索，支持排序、导出统计、编辑附加信息、修改导入前次数与暂停抽选。部门、职位、班级或分组、备注会保存到档案、活动快照和备份中。移除仅归档，保留活动历史。修改名单或撤销活动会取消待确认抽选；刷新可保留待确认结果和上次选择的场景。

常见格式会自动识别，下面这些均可直接粘贴。没有表头时，根据数字、姓名、部门与职位特征判断；有表头时按列名识别，不要求顺序一致。纯数字第三列仍兼容旧版“姓名、编号、次数”格式，并在预览提示核对。不能确定用途的内容保留在备注，不会凭空补全缺失信息。

```text
示例甲  组织部  干事
示例乙  组织部  成员
S-001  示例辛  宣传部  部长
姓名：示例一，学号：001，职位：成员
```

编号保留前导零；重复编号或无编号的同名记录默认不选中，确认导入时后端还会检查重复。重名人员应填写不同编号。无法确定名称或次数无效的行会提示核对，修改后可选中；未勾选的行不会导入。识别按常见文本格式在本机完成，不调用外部模型，不读取图片或 XLSX 文件内容。

```csv
班级,班级编号,历史次数
高一（1）班,101,2
高一（2）班,102,0
```

```csv
姓名,学号,历史次数
示例一,001,2
示例二,002,0
```

每个账号最多 50 个场景，本机最多 100 个账号。每场景最多 2000 个档案（含已移除）、10000 条活动记录。

## 权重

| 策略 | 相对权重 | 参与 0 次与 2 次的权重比 |
| --- | --- | --- |
| 完全随机 | `1` | `1 : 1` |
| 均衡参与（默认） | `1 / (次数 + 1)` | `3 : 1` |
| 优先少参与 | `1 / (次数 + 1)²` | `9 : 1` |

次数等于当前场景中导入前次数，加上尚未撤销的活动次数。使用密码学随机数与指数竞赛法，进行加权不放回抽样。权重不是多人抽选的最终入选概率，也不保证低次数对象一定入选。

## 组合抽选规则

五类规则可同时开启，按账号和场景独立保存；旧数据升级后默认关闭。规则窗口底部实时检查当前人数、参与范围和配额是否可同时满足。可以先保存配置，再调整名单或人数；规则未满足时无法开始抽选。保存规则会取消尚未确认的结果。

| 规则 | 行为 |
| --- | --- |
| 指定与排除 | 从名单搜索对象，安排为自由抽选、指定必选或排除。指定对象计入总名额及其部门、班级和职位名额；暂停、移除、同时排除或命中近期避让时会提示冲突。 |
| 近期避让 | 避开最近 1–100 场有效活动中的所有参与对象，填 0 关闭。只统计当前场景已确认且未撤销的活动，按时间从新到旧排序。 |
| 久未参与优先 | 基础权重乘以等待权重：`1 + 3 × 间隔场数 / max(1, 有效活动总场数)`。刚参加过为 1 倍，无本机参与记录者间隔按有效活动总场数计算。没有活动记录时大家均为 1 倍。导入前次数没有日期，不推测时间。 |
| 部门 / 班级配额 | 选择部门或班级 / 分组维度，为填写的类别设置恰好入选数量。未设置的类别与未填资料者补足剩余名额；0 表示该类别不入选。 |
| 职位搭配 | 为填写的职位设置恰好入选数量，其他职位补足剩余名额。按职位名称精确匹配，部长和副部长分别计算。 |

例如抽 3 人，可以同时设置“组织部 1 人、宣传部 2 人”和“部长 1 人、干事 2 人”，并指定一名组织部部长；其余两名必须满足宣传部和干事的交叉要求。没有可行组合时会说明冲突，不会减少名额或跳过规则。

执行顺序为：排除暂停、移除、排除名单及近期参与者；保留指定对象并扣除对应名额；在剩余对象中按权重抽选，满足两组配额。通过每人独立的指数随机优先分数与最小费用流寻找满足全部约束且分数合计最小的组合。没有配额时与原有加权不放回抽样等价；有配额时最终入选概率同时受组合约束影响。久未参与仅提高权重，不保证必选。

待确认名单会标注指定参与对象，活动记录和 JSON 备份会保存当次规则快照。重新抽选不计数，撤销活动后近期避让和等待权重随之更新。表格中的权重列为基础权重，不代表叠加规则后的最终概率。清空规则需要在规则窗口点保存才会生效，取消不保存。

## 数据管理

“数据管理”对当前场景操作：导出备份、恢复同类型备份、清空当前名单或删除场景。删除与清空须确认，不影响其他场景或账号。账号至少保留一个场景。

场景 JSON 包含完整名单与记录，不含账号信息，可在另一个账号的同类型场景恢复。CSV 为统计表，不用于完整恢复。

默认文件：`%USERPROFILE%\.dsh\storages\class-picker\state.json`。设置 `DSH_HOME` 时保存到该目录的 `storages/class-picker/state.json`，也可通过插件行 `config.dataFile` 指定完整路径。主文件包含本机账号与全部场景。

每次修改先写临时文件，成功替换后才更新内存与界面；`state.json.backup` 保留上一版。读取失败会保留原文件并报错，不会静默清空。同一宿主进程的多窗口操作有场景版本检查；desktop 与 web 等不同宿主进程同时运行时，应设置不同 `dataFile`，避免写同一文件。

## 独立预览与测试

双击 `启动预览.cmd`，复制终端打印的完整地址到浏览器，保留 `#access=...`。也可执行 `node dev-server.mjs`。需要 Node.js 20.11+，默认仅监听 `127.0.0.1:3217`。预览数据在项目 `.local-data/state.json`，与正式插件独立。关闭终端停止服务。

```powershell
node --test test/*.test.mjs
node scripts/pack.mjs
```

`test/rules-ui.e2e.mjs` 覆盖五类组合规则、交叉名额、冲突拦截、规则保存、历史快照、清空与取消、手机布局。

`test/ui.e2e.mjs` 使用 Playwright 和 Edge，验证注册、登录、退出、改密码、四类场景、场景切换与删除、导入、抽选、确认、刷新、编辑、暂停、撤销、备份恢复与手机布局，并在 `artifacts/` 保存截图。可用 `PLAYWRIGHT_MODULE` 指定 Playwright 目录、`PLAYWRIGHT_CHANNEL` 指定浏览器；生产插件不依赖 Playwright。

本插件提供可视工作台，未注册自然语言工具。

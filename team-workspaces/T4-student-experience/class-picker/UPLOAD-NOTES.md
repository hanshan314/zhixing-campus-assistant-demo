# 选人插件（T4 协作贡献）

这是“轮到你啦”本机账号与抽签工作台的源码、测试和独立预览入口，作为 T4 学生端体验贡献上传到协作区。

本次贡献只包含源码、测试、语言文件、启动脚本和插件打包脚本。原项目中的本机账号、密码哈希、会话摘要、名单、学号、活动记录、截图和压缩安装包均未上传；文档和测试中的姓名、编号和班级示例已替换为虚构值。

在本目录执行：

```powershell
node --test test/*.test.mjs
node scripts/pack.mjs
```

`启动预览.cmd` 和 `dev-server.mjs` 用于本机预览。运行状态写入本机 `.local-data/`，该目录被忽略，不应提交。

本贡献不代表真实学校身份、真实学生资料、生产数据库、正式 Harness 安装验收或发布。

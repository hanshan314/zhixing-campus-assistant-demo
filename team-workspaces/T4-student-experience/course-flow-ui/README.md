# 课序网页测试版

校园工作流的独立浏览器测试界面，静态站点。页面载入 `school-workflow` 导出的任务快照和流程目录，网页测试修改保存在当前浏览器，不写回原始Python台账。

功能包括 PDF/PPTX/DOCX/TXT/Markdown 内容导入、粘贴正文、11类内容分流、手动调整组合流程、工作包草稿、建议时间表、任务状态切换、补充信息、JSON导出和正式截止ICS导出。

PDF使用浏览器内的PDF.js读取每页文字，保留页码，包含中文字体映射资源。纯扫描件提示OCR；混合文件会标出没有文字的页；加密和损坏文件有明确错误信息。当前支持10MB以内、200页以内的PDF。原文件不会上传到服务端。

PowerPoint 支持 PPTX、PPTM、PPSX，使用本地 JSZip 和浏览器 XML 解析器读取，不执行宏或访问外部链接。按实际幻灯片顺序提取页面文字、表格和演讲者备注，保留页码并标注隐藏页。图片、图表和 SmartArt 的读取缺口会明确提示；纯图片课件需先 OCR。支持10MB以内、200页以内的演示文稿；旧版 PPT 请先另存为 PPTX 或 PDF。读取结果进入现有分流和排期流程。

PPT和Word成品通过回到聊天调用对应技能继续生成；本页清楚区分草稿与待制作产物。

识别到需要制作PPT时，分流预览会自动生成包含正文、主题、听众、时长、页数、日期、场景要求和核验条件的提示词。支持编辑、一键复制和TXT下载，并保存在工作包中。参考教学PPT、仅参会及明确无需PPT不会自动产生对应制作提示词。

材料列表使用“PPT制作”作为统一入口，制作任务书和生成提示词均在其中，不再单列对应文件卡片。点击“查看制作要求”即可展开任务书、查看完整提示词、复制或下载。资料收集计划和办理核对表不再显示为材料卡片，已有工作包同样适用。

工作台卡片和详情页均可删除整个大任务，删除后从工作台、时间表和资料列表移除，可从“已删除大任务”恢复。子任务只保留“待办、已完成、删除”三个直接操作，不再使用状态更新窗口；已删除子任务可恢复到原状态。旧状态会转换为待办或删除，并保留历史。已完成任务的完成记录会保留；删除未完成任务后，它不再计入待办和进度分母。所有变更仍只保存在当前浏览器。

完成时间表按建议完成日期划分为此前、今天、明天、本周、下周、更晚和日期待定，周从星期一开始。今天和明天优先单列，空区块自动隐藏，每区显示任务数量并按时间排序。筛选和搜索同时作用于各区；正式截止保持独立，不把建议日期视为学校截止。

大任务和子任务的回收站提供“清空回收站”。清理前列出待清理范围、数量并再次确认，永久清理只处理确认时已选中的已删除记录。子任务清理保留完成数量统计并移除残留的依赖引用；大任务清理同时移除其中的原文、材料和子任务。浏览器存储写入失败时保留原有数据。清空后无法通过恢复入口找回。

更新快照：运行 `export_data.py`。校验：运行 `node tests.mjs`。本地预览：使用静态HTTP服务器服务 `dist/`。
